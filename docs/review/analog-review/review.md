# Analog subsystem review

Review scope: U4 PCM3060PWR; U12 ST TL074IDT; U13/U14/U15 Microchip MCP6004T-I/SL; U16 TI LM4040C10IDBZR; nominal MMBT3904 Q1/Q2. The actual Q1/Q2 manufacturer/order code remains unresolved. This is an independent read-only review of the current native XML netlist, analyzer JSON and raw KiCad files, compared with official Rev3 Patch SM schematic and manufacturer PDFs. No schematic/PCB changes or routing were performed.

## Required changes

1. **CV supply mismatch, confirmed production blocker.** U13/U14 pin 4 is on +5V; outputs feed the eight MCU ADC pins directly with no series resistor. Official Rev3 sheet 4 instead powers the corresponding U7/U11 from +3V3_A. Nominal demand is `1.65 - 0.33 Vin`: a -12V external CV demands 5.61V and drives a 5V-powered opamp toward its upper rail. STM32 DS12556 Rev8 PDF p94 explicitly limits FT_a ADC mode input to 4V absolute maximum. The Patch SM datasheet PDF p5 (printed p2) rates CV inputs between negative and positive power rails. Move the input opamp supplies and local bypasses to a reviewed 3.3V analog domain and validate all power-sequence/overrange cases. Matching the rail protects the voltage range, but alone does not validate rail sequencing, recovery or backpowering.

2. **Gate output impedance mismatch, confirmed production blocker.** R162/R163 are 1k; published Patch SM gate output impedance is 100R (PDF p12, printed p9). Official Rev3 uses a noninverting 120k/62k gain stage and 100R output isolation. This clone instead uses saturated MCP6004 comparators with 1.65V threshold. Digital polarity is noninverting in both; unmodified firmware will command nominal low/high, but output loading, edge response and saturation recovery have not been demonstrated equivalent. Restore reviewed 100R isolation and prefer the published gain topology unless independent testing supports a replacement.

3. **Bypass placement needs redesign.** MCP6004 datasheet PDF p14 specifies a 0.01–0.1uF bypass within 2mm. Actual nearest 100nF centre distances from VDD pad centre: U13 9.006mm, U14 5.546mm, U15 1.630mm; all these bypasses are on the opposite PCB side. For U12 the nearest 100nF centres are 22.354mm from +12V pin4 and 28.788mm from -12V pin11. Raw footprint pad offsets were checked, so the distance is to the supply pad rather than package centre. These are geometric facts, not proof of measured oscillation. Reposition dedicated caps near their own supply pads with short GND returns. U15 projected proximity alone does not validate via loop inductance.

## Qualified risks and source conflicts

- **Negative gate stress is also present in the published reference.** Q1/Q2 use 100k series and 1M base pulldown with grounded emitter and no explicit B-E reverse clamp. An unloaded -12V input demands -10.909V at the base. Nominal onsemi MMBT3904L PDF p1 rates VEBO=6V; the external voltage that reaches this limit is -6.6V. The official reference has the same topology, while its module specification allows gate input down to negative supply. Neither copying the reference nor current-limited junction avalanche proves compliance with the exact chosen transistor rating. Resolve the vendor/order code, then add a reviewed anti-parallel base-emitter clamp or obtain a manufacturer-supported operating envelope. Do not assert this is a missing diode relative to Rev3.
- **CV output rail headroom is inherited, not a new mismatch.** `1+62k/120k = 1.5166667`; DAC 3.3V demands 5.005V before the 100R output resistor, on a nominal +5V supply. Reference uses the same rail and gain. MCP6004 p3 specifies finite output swing, so the ideal loaded result 5.000V is not a real-device endpoint guarantee. Measure/model loading, supply tolerance and temperature; changing this gain casually would break stock volts-to-DAC behavior.
- **Audio input impedance specification disagrees with reference resistor value.** Published application says 100k input impedance, while reference and displayed clone values use 66.5k after a 2.2uF coupling cap. The ordered C100/C103 part is 22uF, as documented below. Preserve the reference for firmware/audio gain first; treat the nominal impedance claim as a source discrepancy requiring clarification rather than infer a new 100k value.
- **Audio input coupling BOM differs by tenfold.** C100/C103 display 2.2uF, consistent with the official Rev3 input-coupling values, but their exact MPN `CL21A226MAQNNNE` and LCSC C45783 identify Samsung **22uF, ±20%, X5R, 25V, 0805**. Evidence: `../baseline/component-inventory.csv`, `../power-fab-review/C45783-product.json`, and the Samsung catalog retained as `../power-fab-review/C45783.pdf`; exact source https://www.lcsc.com/product-detail/C45783.html. With the native 66.5k input resistor, an ideal zero-source-resistance coupling high-pass has `fc = 1/(2πRC)`: **1.08787Hz for displayed/reference 2.2uF**, versus **0.108787Hz for the nominal ordered 22uF**. The resulting additional 20Hz attenuation is about0.01283dB versus0.0001285dB, respectively, before the other input/filter stages. These are nominal coupling-stage calculations, not complete audio transfer measurements; source impedance, MLCC bias/tolerance and opamp/codec behavior remain unmodeled. Future correction must reconcile intended value and exact orderable part before changing either. The accepted CV-rail/gate-resistor candidate does not change C100/C103.
- **Audio overrange requires qualified protection.** Codec analog pins are rated -0.3 to VCC+0.3; TL074 runs from +/-12V and can drive beyond codec rails during startup/unpowered codec and large signals. Existing 1k series input resistor helps bound current but does not alone establish the codec absolute voltage limit. Native netlist contains no external input clamps. TI PCM3060 p40 illustrates a protected input circuit. Require fault/power-sequencing checks at the intended typical ±12V operation and review survival at the published absolute limits; those limits do not guarantee full analog performance. No codec-damage occurrence is claimed.

## Positive crosschecks

- Every used U4 pin matches manufacturer terminal table PDF pp7–8 and conventional TSSOP28 pad order. VCC24=+5VA; VDD7=3.3V; AGND23/22, SGND16, DGND8 all GND; MODE28 directly GND selects I2C; ADR27 GND gives 7-bit 0x46 (p27), matching unmodified libDaisy. RST15 held at 3.3V matches driver assumptions. ADC25/26 and DAC20/19/18/17 channels and polarities agree. Zero outputs13/14 intentionally unconnected. 5V analog and3.3V digital are within recommended ranges when their supplies are present.
- U12 pins all match ST TL074IDT SO14: 1/7/8/14 outputs, 2/6/9/13 minus,3/5/10/12 plus,4 VCC+,11 VCC-. SOIC14 1.27mm footprint numbering and package class agree. MCP6004 has the same used pin ordering (p1/table3-1), so reusing the TL074 symbol with MCP6004 value did not introduce a pin swap.
- U16 TI DBZ pin1 cathode=GND, pin2 anode=-10V reference, pin3 floating is valid for the negative shunt arrangement (TI p4 permits pin3 floating or tied to anode). R1702k from -12V yields nominal1mA feed; eight200k virtual-ground branches use0.4mA, leaving0.6mA shunt, above125uA full-temperature minimum (p23). The nominal headroom calculation needs negative supply magnitude of approximately11.05V to retain the stated minimum shunt current with this load. This qualifies low-voltage regulation behavior, not a violation of a guaranteed operating range: the Patch SM datasheet lists ±6…17V under **Absolute Maximum Ratings**, and its electrical characteristics identify typical ±12V operation. It does not guarantee unchanged analog performance at ±6V.
- Codec VCOM is pin21, not pin20 despite a typo in datasheet narrative p23. Pin table p8 and diagram p7 identify21. Two JFET TL074 bias inputs load it far less than its ±1uA allowable load (PCM p3);10uF decoupling plus local0.1uF is consistent. Pin-table/raw-pin evidence takes precedence over the narrative typo.
- Displayed audio input and differential MFB R/C values agree with Rev3 sheet2; this is a schematic-value comparison rather than confirmation of all ordered component values:66.5k/15k/220pF input,18k/66.5k/39k/100pF/18pF output,100R isolation. The ideal independent bench reproduces approximately2.1645 gain at100Hz and2.1168 at20kHz with100k load. Topology matches TI differential-to-single-ended example p40. Fullscale PCM differential8Vpp yields about17.33Vpp unloaded; this is consistent with the same reference gain but requires real-device clipping/noise/THD checks at actual supply/load.
- Q1/Q2 schematic/PCB pads use1B2E3C matching the nominal onsemi SOT23 datasheet; this does not certify the unidentified C20526 vendor.

## Layout constraints for the 4-layer-first design

Keep an unbroken adjacent ground reference below analog paths and codec digital clocks; separate digital clock/memory routes by placement rather than cuts in GND. Cluster U4 and U12 audio filter components, keep VCOM quiet/short, avoid switching-current returns through VCOM/analog ground, place input coupling and output resistors near relevant interfaces. Keep each MFB loop and paired differential path compact and symmetric; do not run digital aggressors beside high-impedance summing nodes. Put U13/U14 close to input resistor clusters and MCU ADC side with short outputs and local3.3V decoupling; put the -10V shunt/filter close enough to distribute a quiet bias reference. Keep gate connector series/clamp paths local and return their fault currents away from ADC/VCOM. Plane continuity, loop lengths and protection placement matter more than adding layer count. Six layers is a fallback only after route/reference analysis; eight is the last resort.
