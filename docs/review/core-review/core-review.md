# Digital core independent review

This read-only review covers U1 STM32H750IBK6, U3 IS42S32160F-6BLI, U2 IS25LP064A-JBLE, Y1 X322516MLB4SI, reset and boot circuitry. Evidence comes from native KiCad XML, embedded PCB pad data, native `pcbnew`, manufacturer PDFs and pinned official firmware. It is a subsystem review, not a release certificate.

## Required corrections

**1. Stock firmware refresh violates U3's published retention requirement.** Official libDaisy commit `08087203debc646d3710ec8caa35bac6cf20ab5e` configures PLL2 N=12, M=1, R=1 and FRACN=4096. With the required 16 MHz HSE, FMC receives 200 MHz; SDClockPeriod=2 yields SDCLK=100 MHz. The programmed refresh COUNT is `0x81A-20` = 2054. ST RM0433 Rev9 pp877–878 explicitly clocks the counter with SDCLK and defines COUNT+1 clocks between refresh requests. Consequently 8192 rows are refreshed in **168.3456 ms**, while ISSI RevB pp1,16 requires **8192 refreshes per 64 ms** through 85°C. This 2.63× mismatch is independent of routing quality. A conservative register value at 100 MHz would be 761 including ST's 20-cycle scheduling allowance. Applying that value privately to application or bootloader firmware would breach the unchanged-firmware requirement. A short memory test does not establish retention compliance.

Do not restore the Alliance MPN named in an old firmware comment blindly: AS4C16M32MSA-6BIN's manufacturer datasheet pp14–15 specifies the same 8K/64 ms requirement and **1.7–1.95 V operation**, incompatible with these 3.3 V rails. The official PatchSM schematic is explicitly reduced and omits the MCU/SDRAM core sheets; it does not establish the actual original memory MPN. No manufacturer-supported 3.3 V, 16M×32 memory with retention covering this interval was established here. That is a missing proof, not proof that no suitable part exists. Resolve the reference hardware and approved stock firmware combination before locking RAM or declaring firmware compatibility. Manufacturer clarification, an officially corrected stock initialization or a memory with proven suitable retention is required.

**2. Y1 cannot be assembled with its ordered footprint.** Schematic and PCB specify `Crystal_SMD_3215-2Pin_3.2x1.5mm` with two pads. The manufacturer YSX321SL sheet supplied for C13738 / X322516MLB4SI, p1, shows a **3.2×2.5 mm, four-pad** crystal: terminals 1 and 3 are the crystal, 2 and 4 are grounded case. LCSC ordering data independently identifies `SMD3225-4P`. Rotation cannot fix the mismatch. Select the correct four-pad symbol/footprint, ground the case lands and retain 16 MHz; alternatively source a verified, genuinely matching two-pin part.

**3. MCU bypass and HSE placement must be rebuilt.** VCAP ball F13 is 12.280 mm from C13.1 and 29.422 mm from C14.1. Ball M10 is 15.158 mm and 32.039 mm away respectively. The schematic labels both caps 2.2 µF, but both BOM fields actually order CL10A226MQ8NRNC / C59461, a 22 µF ±20%, 6.3 V X5R part. This is a tenfold nominal-value mismatch in addition to the remote placement. Samsung catalog PDF p20 lists CL10A226MQ8NRN as 22 µF; the exact LCSC product confirms the complete suffix. Neither nominal value nor local placement is acceptable as ordered. ST DS12556 Rev8 pp92,196 requires each supply pair's capacitors as close as possible to, or below, its pins; pp96,201 requires 2.2 µF ±20%, ESR <100 mΩ. Ordinary VDD balls' closest 100 nF caps are approximately 5.17–8.36 mm away; VDDA/VREF's closest 100 nF is over 20 mm away. Place dedicated bypasses directly by or under the balls with short ground vias.

HSE load capacitor C37.1 is 38.968 mm from G1 and C38.1 is 37.593 mm from H1. Each cap is also over 42 mm from the crystal's nearest signal pad. ST DS12556 pp115,219 expressly requires the crystal and load capacitors close to the oscillator pins. Rebuild the complete crystal loop at G1/H1, away from memory clocks and switcher currents.

**4. Crystal load remains unresolved.** Two 18 pF caps contribute 9 pF series capacitance before pin, package and board strays. Specific C13738 ordering metadata says CL=9 pF; positive stray raises the effective load above that value. The generic manufacturer sheet permits specified loads but does not decode this exact order suffix. Obtain exact manufacturer ordering confirmation, recalculate C1/C2 for final geometry and verify startup margin and frequency on hardware. This is a supported concern, not a demonstrated oscillator failure.

## Complete package and pin checks

- **U1 passes all 201 balls.** ST DS12556 p56 Figure7 gives the full UFBGA176+25 top-view map. The 201-pad footprint correctly represents that package. Pages318–320 specify 10×10 mm, 0.65 mm pitch and 0.300 mm lands. Every ball function agrees with the native schematic; native `pcbnew` comparison against the canonical library finds no pad position/size mismatch.
- **U3 passes all 90 balls.** All functions, supply balls and five NC balls agree with ISSI p4. Four banks, 13 row bits, nine column bits and 32-bit width match stock firmware's 64 MiB addressing. A preliminary mirror suspicion was rejected: U3 is on B.Cu, which intentionally reflects local Y. After attaching the canonical footprint to a native board, flipping, positioning and rotating it 180°, all 90 positions and sizes match. No reflected-footprint defect exists.
- **U2 passes all eight pins.** ISSI RevA16 pp7,91,99–100 confirms JBLE is the eight-pin SOIC 208 mil package: 1=CE#, 2=IO1, 3=IO2, 4=GND, 5=IO0, 6=SCK, 7=IO3, 8=VCC. All functions, nets and positions match. C2841348's `-TR` suffix changes packing, not package.
- All **299 IC pad-to-net assignments** match the native schematic, after normalizing hierarchical `/` and five individually isolated NC aliases. See `ballmap-audit.csv`, `ballmap-summary.json` and `package-geometry.json`.
- MCU VDD, VBAT, PDR_ON and VDD33USB connect to +3V3; VDDA and VREF+ to +3V3A; VSS, VSSA and VREF− to GND. VCAP reaches only the bypass capacitors. Nominal rails match operating ranges. Local impedance, capacitor derating and power sequencing remain to validate.

## Firmware, boot and false-positive checks

QSPI capacity is 8 MiB and its PF8/PF9/PF7/PF6/PF10/PG6 assignments match stock firmware. Its divider gives 100 MHz with 400 MHz CPU or 120 MHz with 480 MHz CPU; ISSI p85 permits 133 MHz at 2.7–3.6 V. Read-parameter byte 0xF0 selects eight cycles including two mode cycles; stock two mode plus six dummy cycles agrees with ISSI p20. This establishes configuration consistency, not routed timing or hardware XIP operation.

Missing IO3 pull-up was considered and rejected as a demonstrated initialization defect: STM32 QUADSPI forces IO3 high during single/dual SPI phases, disabling HOLD# (RM0433 p886). R21 provides the 10 kΩ CE# pull-up. Optional weak pull-ups may improve off/reset states, but their absence is not an evidenced blocker here.

BOOT_FLASH uses PG3 through 4.7 kΩ, a 10 kΩ pulldown and a 2.2 µF hold capacitor. Stock reset-to-DFU drives PG3 high and waits 10 ms. Nominal BOOT0 reaches 1.703 V by then, above its **dedicated** 1.161 V VIH minimum at 3.3 V (DS12556 p126; generic 0.7VDD does not apply). Final high is 2.245 V, charge time constant 7.034 ms and discharge time constant 22 ms. Nominal compatibility passes; tolerance and actual boot sampling need hardware validation. NRST has a 10 kΩ pull-up, 100 nF and reset button. PDR_ON tied high enables internal POR/PDR.

PatchSM initialization skips SDRAM reinitialization only for external-memory code running under a pre-v6 bootloader. Internal-flash execution and v6+ apply current initialization. Official DaisyBootloader v5.0.0's libDaisy submodule `38d23a2cc5420aa957f4cdb96454c293318ad0f3` also uses 200 MHz FMC / 100 MHz SDCLK and COUNT=2054. Its RPDelay=0 differs from current16; its exact HAL encoding requires separate review. The current bootloader submodule `24be4afea00d71988019fe8dd9fd9fc8fc5bf72c` likewise retains COUNT=2054. Changing only current applications would not establish compatibility with old bootloaded binaries.

The initial tRAS=4×10 ns=40 ns inference was withdrawn as a definite violation: HAL writes SelfRefreshTime−1=3 into TRAS, while RM0433 p875 documents 0→2 cycles and 1→3 cycles, implying raw3→50 ns. Reconcile this unusual encoding with actual MCU revision before treating it as a defect. Current tRCD=10 clocks also constrains ordinary ACTIVE-to-PRECHARGE sequences. Refresh remains the independent, unambiguous blocker. Other nominal comparisons with ISSI p16 are tMRD=20 ns≥12 ns, tXSR=70 ns≥70 ns, tRC=80 ns≥60 ns, tRP=160 ns≥18 ns, tRCD=100 ns≥18 ns and tWR=30 ns≥12 ns. IO setup/hold and self-refresh transitions are not proven by these comparisons.

## Four-layer-first routing requirements

1. Place U1 and U3 adjacent using their fixed FMC ballout. Preserve every MCU port assignment. Start with four layers and a continuous ground reference beneath primary routing. Document bottom-side SDRAM return paths if the adjacent inner layer contains power regions. Stitch reference returns beside layer transitions.
2. ST's example uses 0.30 mm MCU lands, 0.10 mm pad escape traces, 0.30 mm stencil openings and 100–125 µm stencil thickness (p320). Demonstrate JLCPCB clearance, drill, annular ring and soldermask feasibility before routing completion; pad count alone does not establish four-layer escape feasibility.
3. Place a 2.2 µF low-ESR capacitor locally at each VCAP ball; provide local 100 nF for each of 13 VDD balls plus bulk, local USB bypass and VDDA/VREF bypass matching ST's supply scheme. Check effective capacitance under actual bias.
4. Route FMC clock point to point over continuous ground; reserve a source-series termination site. Define DQ, DQM, address/bank and command timing groups. Derive skew and flight-delay limits from ISSI p16 and the MCU revision's FMC timing tables. Include SDCLK flight delay in read/write timing; a generic length-match limit is not a manufacturer requirement. Avoid stubs and unnecessary vias.
5. Keep QSPI near U1 and reserve clock termination; close timing at both 100 and 120 MHz with actual flash load and MCU sampling. Keep memory clocks out of analog input areas.
6. Make crystal and caps a compact loop at G1/H1; connect case and cap grounds locally without shared switch-return current. Tune loads for the exact ordered CL. Preserve 16 MHz.
7. After every routing operation: refill zones, run native DRC/unconnected and copper hygiene checks, then independently compare end-to-end connectivity. Six layers are acceptable after an evidenced four-layer failure; eight are the last resort. Twelve layers are excluded from the deliverable.
